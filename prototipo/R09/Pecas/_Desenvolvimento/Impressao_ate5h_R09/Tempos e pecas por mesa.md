# Distribuicao por tempo — R09

Projeto principal: Robo Cartografico A4 Desmontado.3mf. Abra como PROJETO no OrcaSlicer.

41 pecas inteiras em13 mesas. Perfil PLA do usuario: bico0,4, camada0,2,3 paredes,15% crosshatch e suportes normais automaticos. As faces de apoio foram preservadas; as pecas foram reposicionadas no plano da mesa.

Nove mesas abaixo de5 horas; variacao entre elas de6min46s. As outras quatro sao excecoes individuais aprovadas pelo usuario para preservar as pecas inteiras.
